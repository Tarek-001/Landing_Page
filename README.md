# Landing_Page

A responsive landing page for a fictional watch brand, built to practice
CSS Flexbox, layout, and responsive design fundamentals.

## 🖥️ Live Demo
[View the live site](https://tarek-001.github.io/Landing_Page/)

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox)

## ✨ Features
- Hero section with background image and call-to-action
- Feature highlights section with images and descriptions
- Customer quote/testimonial section
- Footer CTA with sign-up button

## 📚 What I Learned
- How flexbox handles sizing, shrinking, and alignment
- Structuring reusable component-style sections (box + caption pairs)
- Debugging image fitting issues with `object-fit` and `overflow`
